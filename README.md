# Obsidian Publisher

将 Obsidian 文档转换为微信公众号兼容的富文本格式，一键复制到剪贴板，粘贴后保留完整排版样式。

## 功能

### 核心转换（已验证）

- **一键复制**：将当前 Markdown 文档转换为带内联样式的 HTML，写入剪贴板的 `text/html` 格式
- **预览弹窗**：模拟手机宽度预览效果，可拖拽移动，支持预览后再复制
- **右侧预览面板**：在 Obsidian 右侧分栏实时对比原文与公众号预览效果，切换文件自动刷新

### Obsidian 语法支持

| 语法 | 转换结果 | 状态 |
|------|----------|------|
| `[[WikiLink]]` | 灰色文字（不可点击，保留引用语义） | ✅ 已验证 |
| `==高亮==` | `<mark>`，颜色跟随主题 | ✅ 已验证 |
| `~~删除线~~` | 删除线，颜色跟随主题（和 Obsidian 一样是浅灰色） | ✅ 已验证 |
| 无序 / 有序列表（多层嵌套、松散列表、引用块和 Callout 中的列表） | 圆点、序号、缩进线颜色跟随主题，粘贴后嵌套层级不变，间距与 Obsidian 一致 | ✅ 已验证 |
| 任务列表（7 种状态） | 勾选框图标，见下表 | ✅ 已验证 |
| `> 引用` | 左侧 accent 色竖线（2px） | ✅ 已验证 |
| `> [!note]` Callout 块 | 带标题的样式块，颜色/图标跟随主题 | ✅ 已验证 |
| 代码块 | 语法高亮（"当前 Obsidian 主题"下用 Tokyo Night 配色，静态预设主题各有自己的代码配色） | ✅ 已验证 |
| `[^1]` 脚注 | 上标引用 + 底部定义区（微信兼容，无锚链接） | ✅ 已验证 |
| `$...$` / `$$...$$` 数学公式 | PNG 图片（MathJax 渲染，编辑/阅读模式均支持） | ✅ 已验证 |
| Mermaid 图表 | PNG 图片（深/浅色模式自动切换配色） | ✅ 已验证 |
| Frontmatter | 自动移除 | ✅ 已验证 |
| `#tag` 标签 | 自动移除 | ✅ 已验证 |
| `%% 注释 %%` | 自动隐藏（行内与整块注释均支持，代码块里的不受影响） | ✅ 已验证 |
| `![[image.png]]` | 图片（支持宽度限制 `![[img.png\|300]]`） | ✅ 已验证 |
| `![[note.md]]` | 内联展开被嵌入的笔记（最大递归深度 3） | ✅ 已验证 |

### 任务列表状态

| 语法 | 图标 | 颜色 | 内容样式 |
|------|------|------|----------|
| `- [ ]` | 空框 | 灰色边框 | 正常 |
| `- [x]` | ✓ | 主题 accent | 灰色 + 删除线 |
| `- [/]` | / | 蓝色 | 正常 |
| `- [-]` | – | 灰色 | 灰色 + 删除线 |
| `- [>]` | › | 琥珀色 | 正常 |
| `- [?]` | ? | 黄色 | 正常 |
| `- [!]` | ! | 红色 | 正常 |

上表是默认配色。选择"当前 Obsidian 主题"时，勾选框直接截取 Obsidian 中的实际显示效果，形状、颜色、符号与你使用的 Obsidian 主题完全一致（首次转换时窗口左上角会极短地闪现几个勾选框，这是在截图）。已完成（`[x]`）的打勾颜色跟随所选主题的强调色；静态预设主题还可以覆盖其它状态的颜色，比如简约黑白一/二全部改为灰阶。

### 主题适配

插件在转换时从当前 Obsidian 主题读取实际 CSS 变量，预览和输出样式跟随主题自动适配：

- 文字颜色、强调色（accent）
- 正文背景色：Obsidian 处于浅色模式时不带背景色，由公众号页面自己决定；深色模式下保留深色背景（否则浅色文字在公众号白底上看不清）。静态预设里的冷酷的仙境、橙心、中国红、紫雾、深蓝、森林、樱花同样不带背景色
- 标题颜色（H1–H6 各级独立读取），以及标题下划线（主题本身有下划线才会显示）
- 斜体颜色、高亮背景色与文字颜色
- Callout 配色与图标（13 种类型，读取 `--callout-color` / `--callout-icon` CSS 变量）
- 代码块背景色

已测试主题：**Blue Topaz**、**Minimal**、**Default**

发布主题（设置或预览面板的下拉框中可选，和 Obsidian 自己的编辑器主题是两回事）：
- **当前 Obsidian 主题**：跟随当前激活的 Obsidian 主题实时取色（推荐）；标题、代码、表格的字号按该主题与正文的比例换算，正文固定 16px，H1、H2 分别不超过 28px、24px，避免在手机上过大
- 11 款静态预设，不随 Obsidian 主题变化，按场景设计：
  - 均为精修主题（有专门设计的 H2 装饰，均在公众号实测过）：冷酷的仙境、橙心、中国红、简约黑白一、简约黑白二、紫雾、杏仁、深蓝、森林、樱花、星云（唯一的深色主题）

## 安装

### 手动安装（推荐）

1. 前往 [GitHub Releases](https://github.com/agiledolphin/obsidian-publisher/releases/latest)，下载 `main.js`、`manifest.json` 和 `styles.css`
2. 在 vault 中创建目录 `.obsidian/plugins/obsidian-publisher/`，将三个文件放入（缺少 `styles.css` 时预览面板的布局会错乱）
3. 在 Obsidian：**设置 → 第三方插件 → 关闭安全模式 → 启用 Obsidian Publisher**

### 开发模式安装

```bash
# 1. 克隆并安装依赖
cd obsidian-publisher
npm install

# 2. 构建（生产）
npm run build

# 3. 开发模式（自动监听修改）
npm run dev

# 4. 软链接到你的测试 vault
ln -s $(pwd) /path/to/your/vault/.obsidian/plugins/obsidian-publisher
```

然后在 Obsidian：**设置 → 第三方插件 → 关闭安全模式 → 启用 Obsidian Publisher**

## 使用

1. 打开一篇 Markdown 文档
2. 右键文件 → **打开公众号预览面板**，在右侧分栏对比原文与预览效果
3. 确认后点击预览面板中的「复制到剪贴板」，或执行命令「复制为公众号格式」
4. 打开微信公众号编辑器，`Ctrl+V` 粘贴
5. 如果使用了带色块横幅/边框盒子装饰的标题主题（如简约黑白、橙心），粘贴后检查一下微信编辑器工具栏的「行间距」设置——默认 1.6 倍会让这类标题看起来偏高，手动调成 1.0 即可恢复正常（详见下方已知限制）

也可通过命令面板（`Ctrl/Cmd + P`）访问以下命令：

| 命令 | 说明 |
|------|------|
| 复制为公众号格式 | 直接转换并复制，不打开预览 |
| 预览公众号效果（弹窗） | 弹窗预览，可拖拽移动 |
| 打开公众号预览面板 | 打开右侧分栏预览 |

## 已知限制

- **图片**：本地图片转为 base64 嵌入，粘贴后微信编辑器会自动处理；外部图片依赖微信抓取，行为不稳定
- **列表和引用块**：为了让多层嵌套列表保持正确层级、引用块不被公众号额外加上一条灰色竖线，两者都以排好版的段落块输出，而不是公众号编辑器原生的列表和引用格式；粘贴后在公众号里按回车不会自动续出新的列表项
- **紫雾、星云主题粘贴时的「内容结构检测」提示**：这两个主题的二级标题是渐变文字，粘贴到公众号时编辑器会弹出「文字背景尽量不要使用渐变」（`darkmode-no-gradient`）的提示，点「继续插入」即可。提示只有作者自己看得到；读者在浅色模式下看到渐变，在深色模式下微信会去掉渐变、改成纯色文字（颜色由微信决定，星云实测是青色），两种模式都能正常阅读
- **星云在读者深色模式下的背景**：微信深色模式会把星云的深色正文背景调亮成偏亮的靛蓝，这是微信对文章背景的统一处理，文字仍然清楚
- **Mermaid 颜色**：使用 Mermaid 内置深/浅色主题，不完全匹配 Obsidian 当前主题配色
- **微信编辑器「行间距」设置**：微信公众号编辑器工具栏有一个全局行间距倍数，新建文章默认 1.6 倍，会在粘贴内容本身的样式基础上再放大一层。标题文字行紧密堆叠的装饰（简约黑白的边框标题、橙心的色块横幅）对此比较敏感，粘贴后可能看起来偏高；手动把这个工具栏设置调成 1.0 即可恢复正常。这是微信编辑器的全局设置，不是粘贴内容自带的样式，无法从插件这边直接覆盖
